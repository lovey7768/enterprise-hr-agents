## How to Add Screenshots

1. Take screenshots of your Streamlit application running the multi-agent HR workflow
2. Save them with the exact filenames listed above
3. Replace the placeholder references in this folder
4. Commit and push to update the README display

### Recommended Screenshot Dimensions
- **Width**: 1200-1400px
- **Format**: PNG (lossless)
- **Quality**: High-resolution (150% zoom recommended)

### What to Capture

**demo-screen-1.png**: Show the initial intake form with:
- Job description text area
- Candidate salary expectation field
- Max role budget field
- Work authorization dropdown

**demo-screen-2.png**: Show the resume upload section with:
- Drag-and-drop file upload area
- Uploaded file indicator (demo shows "lovepreet...GINEER.pdf")
- Parsing status indicator
- Raw text preview pane

**demo-screen-3.png**: Show the screening results with:
- Match score display (e.g., "17.0/100")
- Decision status (REJECT/APPROVE)
- Screening audit section
- Compliance audit checklist
- Targeted questions section

**demo-screen-4.png**: Show the final operations section with:
- Generated rejection/offer letter
- Action buttons (ACCEPT/REJECT)
- HITL checkpoint indicator
- Final decision memo
